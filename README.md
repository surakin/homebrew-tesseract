# homebrew-tesseract

Homebrew tap for [Tesseract](https://surakin.github.io/tesseract/), a native desktop Matrix client built on the Matrix Rust SDK.

## Installation

```sh
brew install --cask surakin/tesseract/tesseract
```

Or tap first, then install:

```sh
brew tap surakin/tesseract
brew install --cask tesseract
```

## Requirements

- macOS Ventura (13) or later
- Apple Silicon or Intel

## Upgrading

```sh
brew upgrade --cask tesseract
```

## Uninstalling

```sh
brew uninstall --cask tesseract
# also remove app data, caches and preferences:
brew uninstall --cask --zap tesseract
```
